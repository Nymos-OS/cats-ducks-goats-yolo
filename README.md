# Cat, Duck, and Goat Detection and Tracking (YOLO11s + ByteTrack)

- Model: YOLO11s, trained on Google Colab (T4 GPU)
- Classes: cat, duck, goat
- Validation performance: mAP50 0.828, mAP50-95 0.712
- Files
  - best.pt: trained model weights
  - demo_*_5s.mp4: 5-second tracking demo videos for each class
  - cats_ducks_goats_yolo.ipynb: notebook for training and demo generation
- Dataset images are not included due to privacy concerns.
